# index.html kuralları
- Tek dosya yapısını koru; ayrı CSS/JS dosyasına bölme (kullanıcı isterse hariç).
- Stil değişikliğinde `:root` renk değişkenlerini ve mevcut font ailelerini kullan.
- Mobil uyumu bozma: değişiklikten sonra dar ekranda (≤480px) kontrol et.
- Analytics (gtag, G-SXCJRCN9VC) ve meta etiketlerini silme.
- Marka kartları (`#brands`): canlı olanlar `brand-tile live`, yakında olanlar `brand-tile soon`. Boş sosyal linkleri gizli tut.
